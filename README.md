## ⚡ Quick Start

```bash
# Download, chmod, and run
wget https://raw.githubusercontent.com/happyhitzz/wireguard-auto-installer/main/wireguard_installer.sh
chmod +x wireguard_installer.sh
sudo ./wireguard_installer.sh
```
